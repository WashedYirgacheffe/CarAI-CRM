## 三、各页面结构细节

### 线索 `/crm/leads/list`
- 二级 Tab：线索列表 / 我的线索
- 左栏漏斗计数：全部线索 3057、未读线索 2305
- **线索状态机**：待处理 → 完善信息 → 初步触达 → 联系互动 → 已完成线索
- 左栏分组维度：系统标签、线索来源、最近联系时间（最近 N 天内未联系）
- 列表字段：线索名称、邮箱、线索状态、系统标签、线索来源、操作
- 右上：AI 数据助理、新建线索

### 客户列表 `/crm/customer/list`
- 顶部：客群 / AI 客群（新）/ 客群列表
- **客群 = 保存的筛选条件**，每个带实时计数，可嵌套；系统自带「客户阶段自动生成」「国家地区（洲）」「分组」等自动客群
- 预置客群示例：全部客户、我的关注、近 7 天联系客户、近 7 天收到新询盘、7 天内移入公海客户、即将移入公海
- 列表字段：公司名称、客户标签、主要联系人、客户分组、最近动态、最近联系时间、国家地区、操作
- 筛选：客户标签、最近联系时间（最近 N 天内未联系）
- **AI 客群**：用大模型监测数据差异，产出重点待跟进 / 客户资料更新 / 谈单监测

### 公海 `/crm/customer/public`
- 比私海多两列：**最近跟进**、**原跟进人**
- 左栏多两个维度：公海分组、**移入公海方式**
- 客群示例：超过 150 天未联系、美国客户、阿里买家身份

### 客户设置 → 移入公海规则
- 提示「我的客户数：56354 / 无上限」—— 按角色配额
- 「符合移入公海条件时，系统会提前 7 天发送邮件提醒」
- 可配置**最近联系日期参照事件**、**最近成交日期参照事件**（哪些行为算"联系过"）
- 规则按客群生效，每条含：规则名、移入条件（N 天未联系）、生效时间、生效客群
- 实例：F 级普潜客户 60 天未联系 / E 级重签客户 60 天 / D 级拉扯客户 60 天

### 客户详情 `/crm/customer/personal?company_id=...`
顶部：私海/公海徽标、公司名、编号、国家、**客户当地时间（11:12 UTC+1）**、标签、跟进人、客户阶段、客户分组、公海分组、客户星级、评分
操作：合并客户、编辑、写邮件

**AI 客户分析卡**（自动生成，带更新时间）：
- 核心摘要：客户互动总结、国际站行为洞察、客户价值与趋势、背调分析
- 价值分析带**分位数**（历史订单总额 ¥x，分位 98.73%）、订单周期（平均 2–3 个月一单）、风险提示（7 笔订单未付款）
- 下方给出推荐追问（如「过去一年内的订单总成交金额是多少？」）

**联系人卡**：主联系人标记、**写信 N 次成功 N 次**、邮箱、社交平台、职级、性别、头像/名片

**主 Tab**：动态 / 资料 / 商机&交易 / Tips / AI 背调 / 数据分析 / 文档 / 操作历史
**动态子 Tab**：全部(888) / 跟进记录 / 往来邮件 / 聊天记录 / 其它
- 动态由系统自动写入，例：订单被编辑 → 自动记一条（操作人、关联订单、订单金额、产品项目数、订单状态、阿里订单状态）
- 工具：写跟进、AI 写跟进、选择模板、AI 聊天旅程、AI 谈单卡点

#### 资料 Tab 完整字段

**公司常用信息**：公司网址、公司名称、简称、国家地区、客户来源、客户分组、客户阶段、客户星级、客户编号、公海分组、座机

**公司其他信息**：客户账期、默认付款计划、客户类型、年采购额、采购意向、**时区**、规模、产品分组、传真、详细地址、公司备注、公司 logo、客户需求产品

**跟进信息**（全部为系统自动维护的时间戳，这是精华）：
最近联系时间、最近跟进时间、**下次移入公海日期**、最近进入私海时间、最近进入公海时间、**进入公海次数**、最近成交日期、最近发件时间、最近收件时间、最近发 EDM 时间、最近收到阿里 TM 消息时间、最近发送阿里 TM 消息时间、最近收到阿里 TM 询盘时间、最近 WhatsApp 沟通时间、最近企业微信沟通时间、最近 Instagram Messenger 沟通时间、Tips 最近更新时间、最近「写跟进」时间、下次日程时间

**系统信息**：创建人、创建时间、最近修改人、资料更新时间、原跟进人、创建方式、关联线索、最近转化线索创建时间、来源线索、来源详情（店铺）、客群（该客户命中的全部客群）、跟进人更新时间

> 顶部还有提示：「AI 通过近期沟通内容分析，发现有 1 条资料字段有更新」→ 从邮件正文反哺客户资料。

### 商机 `/crm/business/list`
- 看板视图，列 = 销售阶段，支持多套「销售流程」（当前为"默认销售流程"）
- **默认阶段**：询盘 → 报价(135) → 样品 → PI(266) → 复购订单(1)，另有 输单
- 顶部汇总：总销售金额、进行中金额、赢单金额，每列也有小计金额
- 卡片字段：商机名（多为邮件主题）、金额+币种、客户/网址、负责人、结束日期
- 可按创建时间排序、按币种换算、归档过滤
- AI：智能识别商机、AI 自动推进、分析谈单卡点

### 报价单 `/quotation`
- **状态**：草稿 / 已报价 / 已批准 / 已下单 / 已作废 / 已转订单
- 筛选：报价单名称、报价单编号、报价单状态、当前处理人、报价日期
- 操作：下载、新建

### 销售订单 `/order`
- Tab：全部订单 / 阿里信保
- **状态**：草稿 / 已下单 / 待收款 / 待发货 / 已发货 / 已完成 / 售后 / 已作废
- 列：订单号、订单名称、更新日期、订单金额、客户、订单状态、**ERP 状态**、**审批状态**
- 筛选：客户名称、客户简称、订单号、订单名称、订单日期、阿里订单 ID、来源店铺
- 特色：**识别 PI**（上传 PI 文件 OCR 自动建单）、AI 数据助理

### 任务 `/task`
- 说明：「任务是由管理者设置的任务规则触发自动创建」
- Tab：任务完成情况 / 任务设置
- 状态：全部 / 即将超时 / 已超时(1512) / 已完成 / 已忽略
- 类型：跟进客户(179) / 回复邮件(4907) / 回复 TM(705)
- 列：任务状态（显示"超时 2 个月 6 天 4 时"）、公司名称、任务规则名称、执行人、最近动态、最近跟进、创建时间、最近跟进时间、截止时间
- 规则示例：「1 星客户 60 天至少跟进 1 次」

### 审批 `/review`
- Tab：由我审批（待办）/ 由我审批（已办）/ 我提交的审批
- 支持 App & 钉钉便捷审批、高级搜索、编写新审批单

### 通讯录 `/contacts`
- Tab：个人通讯录 / 企业通讯录
- 字段：昵称、邮箱、电话、分组名、备注
- 操作：导入通讯录、新增通讯录、分组管理

### 统计报表 `/statistic/biz/system/report`
- Tab：系统报表 / 我的看板
- 模块分类：目标 / 员工 / 沟通（原[邮件]）/ 线索 / 客户 / 商机 / 产品 / 订单 / **订单毛利**
- 过滤：查看范围（可过滤已删除、已冻结账号数据）、目标、筛选报表
- 每个指标出三张报表：**完成情况 / 变化情况 / 详情**（详情可下钻到单据级，列含绩效来源、成员、计入时间、关联客户、统计对象、考核指标）
- **AI 数据助理**：自然语言问数，预置 60+ 问题模板，例如：
  - 「不同跟进人下超过 30 天没有联系的客户数有多少？」
  - 「今年赢单商机金额同比下降的客户」
  - 「近 1 年，不同客户来源的商机转化率是多少？」
  - 「我私海里哪些客户比较有潜力？」
  - 「帮我找出复购高的大客户」

### 产品设置 `/management/manage/product`
- Tab：产品分组设置 / 产品同步 / **产品字段设置** / 产品规格设置 / **布局设置**
- 分组支持多级（新建下级分组）、可见范围控制

- 产品：产品销售排行、产品销售客户排行、产品销售业务员排行、产品销售趋势对比、产品销售趋势
