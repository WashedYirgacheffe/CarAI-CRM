# OKKI 工作台调研笔记（2026-11-08）

仅记录信息架构与功能点，用于我们自己设计工作台；不复制其品牌、视觉与文案。

## 1. 一级导航（左侧竖排图标栏，深色 #0c163d，宽 72px）

| 菜单 | 路由 | 说明 |
| --- | --- | --- |
| 常用 | — | 用户自己收藏的常用入口 |
| 工作台 | `/dashboard` | 首页 |
| 邮件 | `/pro/mail/inbox?user_mail_id=0` | 支持多邮箱，按 `user_mail_id` 切换 |
| 沟通 | `/talk/hub` | WhatsApp 等即时沟通聚合 |
| 线索 | `/crm/leads/list` | 带未读角标 |
| 客户 | `/crm/...` | |
| 商机 | `/crm/business/list` | |
| OKKI Leads | — | 买家数据库／获客（增值模块） |
| 交易 | — | 报价、订单、回款合并为一个入口 |
| 团队数据 | `/statistic/...` | 报表中心 |
| 协同 | — | 审批、任务、工作报告 |
| 企业管理 | — | 组织、权限、设置 |

要点：
- 一级菜单只有 12 个，二级全部收在模块内部，不做超长树形菜单。
- 图标带未读角标（线索 99+、团队数据 13）。
- 我们当前把报价单／订单／产品拆成了三个一级菜单，可以合并成「交易」。

## 2. 顶栏

- 全局搜索：左侧下拉先选搜索类型（客户 / 联系人 / 邮件 …），右侧输入关键字。
- 右侧：快捷新建（+）、IM、消息中心、在线客服、帮助、头像。

## 3. 工作台头部

- 问候语「Hi {名字}」。
- **时区时钟**：可切换时区（如「东十区：悉尼」），实时走秒。外贸刚需。
- **汇率计算器**：弹出式小工具。
- **工作台配置**：卡片自定义。

## 4. 工作台配置（卡片目录）

分两类 Tab：

**业务组件**
- 目标完成情况
- 任务完成情况
- 日程
- 时区&外汇

**报表组件**（可自由拖到工作台，全部来自报表中心）

- 订单：销售订单状态分布、销售订单金额构成、销售订单回款情况
- 商机：销售漏斗、销售金额预测（基于商机）、商机分布、商机输单原因分布、商机对应客户分布、商机关键行为趋势、商机回款情况
- 客户：客户分布、客户销售金额情况、客户销售趋势、新客户成交转化情况、客户复购情况、预计返单客户、新增客户数变化趋势、客户流失预警（基于销售订单）、客户跟进趋势、重点跟进客户、客户 EDM 发送趋势
- 产品：产品销售排行、产品销售客户排行、产品销售业务员排行、产品销售趋势对比、产品销售趋势
- 沟通：WhatsApp 团队沟通效果趋势、邮件系统标签分布、邮件收发趋势、各分类邮件收发趋势、各分类邮件收发数
- 线索：线索转化情况（按来源）、线索转化漏斗
- 团队：任务完成趋势、任务完成情况、重点资源统计、工作量统计、工作报告提交统计、员工销售漏斗
- 关键行为：商机-关键行为、客户-关键行为、邮件、动态-客户、营销

## 5. 日程卡片

- 视图：周 / 月 / 列表；按月翻页；筛选「我参与的日程」；筛选器、新建、设置、全屏。
- **内置各国节日**，这是外贸场景的亮点：
  万圣节·宗教节日、文化日·日本、人民团结日·俄罗斯、独立日·柬埔寨、
  双十一·中国&东南亚、老兵节·美国、独立日·波兰、勤劳感谢日·日本、
  感恩节·美国、黑色星期五、网购星期一、国庆日·阿联酋
  → 既是节日问候的提醒，也是跨境大促（双十一 / 黑五 / 网一）的营销日历。
- 右侧固定一栏「今日日程」，空态有插画。

## 6. 跟进任务卡片

文案：「基于 AI 分析与管理者配置，为你推荐以下跟进任务。」

分类 Tab 与计数：
- 全部 (99+)
- 消息回复 (99+)
- 客户跟进 (99+)
- 数据洞察 (2)
- 审批 (0)
- 跟单协同 (0)
- 商机跟进 (0)

即：把「待我处理的事」按来源聚合成统一的任务流，带「显示设置」可配置。

## 7. 目标完成情况卡片

- 筛选：时间（本月）＋ 范围（我的企业，仅展示数据范围内参与考核的成员及部门）。
- 分「结果目标」与「过程目标」两类。
- 指标项（每项可点进 `/goal/goalManage/detail?type=1&rule_id=...`）：
  - 邮件营销发送数
  - 新建商机数
  - 赢单商机金额
  - 成交订单金额
  - 已回款金额
- 未配置时显示「未设定目标值」，而不是隐藏指标。

## 8. 任务完成情况卡片

- 按人展示 KPI 达成率，例如：
  - 客户邮件在 24 小时内回复 → 62%
  - 24 小时内回复阿里询盘 → 100%
- 图例：及时完成 / 超时完成 / 未完成。
- 本质是**服务时效类 SLA 考核**，直接挂在工作台上。

## 9. 工作量统计卡片

- 时间范围 + 员工筛选。
- 列：新建线索数、新建客户数、新建跟进，最后一行合计。

## 建议吸收的优先级（对照我们当前进度）

P0 —— 架构层，改动小收益大
1. 工作台改为**可配置卡片**：后端存一份用户级卡片布局（卡片 key + 顺序 + 显隐）。
2. 一级导航收敛：产品／报价单／订单 → 合并为「交易」。
3. 顶栏全局搜索加类型下拉；导航加未读角标。

P1 —— 外贸特色，差异化明显
4. **节日日历**：维护国家 → 节日表，按客户所在国家在日程里显示；覆盖宗教节日与跨境大促（双十一 / 黑五 / 网一 / 斋月等）。
5. **时区时钟** + **汇率计算器**（汇率复用 P2 已有的多币种数据）。

P2 —— 任务与考核
6. **统一待办流**：把待回复消息、待跟进客户、待审批、商机推进聚合成一个任务卡片，先做规则版
   （超过 N 天未跟进、即将掉公海、报价后未回复、询盘未在 24h 内回复），后续再接 AI 推荐。
7. **目标管理**：目标规则（指标 + 周期 + 考核范围）＋ 完成度展示。
8. **SLA 考核**：首次响应时效、邮件 24h 回复率。

P3 —— 报表中心
9. 报表按「订单 / 商机 / 客户 / 产品 / 沟通 / 线索 / 团队」分组，报表组件可直接挂到工作台。
   先做销售漏斗、客户流失预警、工作量统计这三个性价比最高的。
